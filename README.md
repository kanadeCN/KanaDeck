# KanaDeck

一款开源AI错题整理工具

> 前情提要：作为一个从始至终对数学感到苦恼的学生 在大一终于发觉了整理错题的必要性喵！

## 目标解决问题：

市面主要现有如下的几种方案：

| 方案       |                                    问题 |
| :------- | ------------------------------------: |
| 手写错题     |                           太过费时，且不保证美观 |
| 市面错题本app | 需要登录使用，高级功能收费，ai模型不能自定义，自由度低；软件界面臃肿复杂 |
| Agent    |            强大，但需要自己配置环境，且手机使用体验差，过于麻烦 |
本项目意在结合手机环境的便利与通过api调用ai模型的强大性能，简化错题整理流程，节约课余时间。

## 开发

所用技术栈：
- Kotlin

开发环境：
- Android Studio (Fedora44)

支持平台：
- Android 7 及以上 (SDK>=24)
